## 1. Runtime compatibility — verified first

Before choosing any dependency, the model itself was inspected rather than assumed about:

| Property | Value | How established |
|---|---|---|
| Flatbuffer file identifier | **`ET12`** | read from bytes 4–7 of the `.pte` |
| Extended header | `eh00`, header 32 B | parsed from the file |
| Program section | 15,616 bytes | from the extended header |
| Constant segment | ~8.87 MB | file size minus segment base offset |
| Backend referenced | **`XnnpackBackend`, and only that** | string scan of the file |
| Undelegated ATen operators | **none** | zero `namespace::op` strings in the program section |
| Quantization | none | no `quantized_decomposed` references |

**Consequence:** the graph is delegated to XNNPACK in its entirety. The Android runtime needs the XNNPACK backend and nothing else — no portable or optimized kernel registry is required for this model.

**Version match:** the model was exported with ExecuTorch **1.5.1** (Python). `org.pytorch:executorch-android` **1.5.1** exists on Maven Central, published late September 2026. Pinning the Android runtime to the exporting version removes schema-mismatch risk entirely. ExecuTorch v1.5.1 also added explicit schema-version checks for PTE files, so a mismatch would fail loudly rather than produce silent nonsense.

## 4. Two risks worth weighing before you start

**4.1 Your laptop's TLS truncated a 100 MB download today.** The Termux APK download died at 12.3 MB of ~100 MB with `SEC_E_DECRYPT_FAILURE`, and Windows `curl` failed the same way on an 8 MB file before PowerShell succeeded. A 1.2 GB Android Studio download is roughly twelve times the size of the transfer that already failed. Android Studio's downloader does resume, and the SDK Manager retries, so this is recoverable — but budget for repeated attempts rather than a clean single pass.

**4.2 Disk.** `C:` had **64.5 GB free** at the last measurement, so space is not a constraint. The phone had only **5.8 GB free (98 % full)**, which matters for installing the APK plus the existing Termux/Debian environment — but the APK itself will be ~60–80 MB with `arm64-v8a` only.
